# DETECTAREA-I-PREDIC-IA-CRIZELOR-EPILEPTICE-CU-AJUTORUL-DATELOR-EEG

Proiectul “Detectarea și predicția crizelor epileptice cu ajutorul datelor EEG” are ca scop dezvoltarea unor modele de învățare autonomă capabile să analizeze tiparele undelor cerebrale și să identifice stările de precriză. 

Nevoia unei metode eficiente de detectare și predicție a crizelor epileptice este actuală. În special din cauza faptului că există pacienți care nu răspund la tratamentul medicamentos este necesară dezvoltarea unei soluții alternative. 

Proiectul propune o abordare pentru reducerea impactului crizelor asupra vieții pacienților prin combinarea informațiilor din domeniile: bioinfomaticii, neurologiei. Pentru reducerea costurilor asociate spitaliării, tratamentului și prevenirea rănirilor grave, detectarea și predicția crizelor epileptice este ideală. De asemenea, acest proiect contribuie la înțelegerea mecanismelor neuronale ale epilepsiei prin identificarea unor tipare EEG specifice.
